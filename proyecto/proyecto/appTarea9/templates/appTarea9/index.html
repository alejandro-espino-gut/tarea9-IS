hx-swap="none"

1. Like sin tocar el DOM

Envía un POST al servidor que incrementa el contador en memoria. hx-swap="none" hace que HTMX descarte completamente la respuesta: no reemplaza ningún fragmento del DOM. Útil para registrar eventos, votos o auditoría sin cambios visuales inmediatos.

hx-indicator

2. Spinner de carga (petición lenta de 2 s)

hx-indicator="#spinner" le dice a HTMX qué elemento mostrar mientras la petición está en vuelo. El spinner tiene display:none por defecto; HTMX aplica la clase .htmx-request solo durante la espera y la quita al terminar.

hx-vals

3. Agregar tarea con prioridad extra

hx-vals='{"prioridad": "alta"}' inyecta el campo prioridad en el POST sin necesidad de un <input hidden>. Django lo recibe en request.POST junto con los demás campos visibles del formulario.

hx-include

4. Búsqueda con campo externo al disparador

El <input> con id campo-busqueda está suelto en el DOM — sin estar dentro del botón ni en un <form>. hx-include="#campo-busqueda" le indica a HTMX que serialice ese input y lo incluya en la petición GET.

hx-swap-oob

5. Actualización fuera de banda (OOB)

Al completar una tarea, Django devuelve dos fragmentos HTML en una sola respuesta: el <li> actualizado (target normal) y un <span hx-swap-oob="innerHTML"> que HTMX ubica por su id y reemplaza en el encabezado de la página, sin importar dónde esté en el DOM.

    {% for t in tareas %}
  • {% if t.hecha %}✅{% else %}⬜{% endif %} {{ t.texto }} {% if not t.hecha %} {% endif %}
    • {% endfor %}
